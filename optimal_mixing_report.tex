\section{Introduction}
\label{sec:intro}

This report documents a Python pseudo-spectral simulation of the
\emph{optimal mixing problem} for passive scalars on the two-dimensional
torus $\mathbb{T}^2 = [0,1]^2$.
The original MATLAB implementation is due to Gautam Iyer and accompanies the
theoretical work of Lin, Thiffeault and Doering \cite{LTD2011} on optimal
stirring strategies.
The Python port (\texttt{mixing.py}) reproduces all numerical experiments
and extends the codebase with Jupyter notebooks, automated figure generation,
and a packaging structure suitable for reproducible research.

\subsection*{Goals}
\begin{itemize}
  \item Reproduce the MATLAB results in a fully open-source Python stack.
  \item Demonstrate that the $H^{-1}$ mix norm decays exponentially under the
        Lin--Thiffeault--Doering (LTD) optimal velocity.
  \item Characterise how the mixing timescale depends on the support
        size parameter~$a$.
\end{itemize}

% ─────────────────────────────────────────────────────────────────────────────
\section{Mathematical Framework}
\label{sec:math}

\subsection{The Passive Scalar Equation}

We study the advection of a passive scalar $\theta : \Torus\times[0,\infty)
\to \Real$ governed by

\begin{equation}
  \label{eq:pde}
  \partial_t\theta + (u\cdot\nabla)\theta = 0,
  \qquad \theta(\cdot,0) = \theta_0,
\end{equation}

where $u:\Torus\to\Real^2$ is a prescribed divergence-free velocity field,
$\nabla\cdot u = 0$.

\subsection{The Mix Norm}

The quality of mixing is quantified by the \emph{$H^{-1}$ mix norm}:

\begin{equation}
  \label{eq:mixnorm}
  \norm{\theta}_{H^{-1}}^2
  = \sum_{k\neq 0} \frac{|\hat\theta(k)|^2}{4\pi^2|k|^2},
\end{equation}

where $\hat\theta(k)$ denotes the $k$-th Fourier coefficient of $\theta$.
The mix norm is small when $\theta$ has energy distributed across fine scales,
i.e., when the scalar is well mixed.
Under the passive scalar equation~\eqref{eq:pde}, the $L^2$ norm
$\norm{\theta}_{L^2}$ is conserved, while $\norm{\theta}_{H^{-1}}$ decreases
monotonically (for appropriate $u$), making it a natural mixing metric.

\subsection{The Lin--Thiffeault--Doering Optimal Velocity}
\label{sec:ltd}

Among all incompressible velocity fields satisfying the enstrophy constraint
$\norm{\nabla u}_{L^2} \le F$, the one that minimises
$\frac{d}{dt}\norm{\theta}_{H^{-1}}^2$ at each instant is the
\emph{Lin--Thiffeault--Doering (LTD) optimal velocity}
\cite{LTD2011}:

\begin{equation}
  \label{eq:ltd}
  v = -\lapinv \Proj\!\left(\theta\,\nabla\lapinv\theta\right),
  \qquad
  u = F\,\frac{v}{\norm{\nabla v}_{L^2}}.
\end{equation}

Here $\Proj$ is the \emph{Leray projection} onto divergence-free vector fields:

\begin{equation}
  \label{eq:leray}
  \Proj g = g - \nabla\lapinv(\nabla\cdot g).
\end{equation}

The rescaling by $\norm{\nabla v}_{L^2}^{-1}$ enforces the enstrophy
constraint exactly at each instant.

\begin{remark}
  The LTD velocity is the \emph{greedy} optimal: it minimises the instantaneous
  rate of change of the mix norm, not a global functional over time.
  It is not known in general whether this greedy strategy is globally optimal
  \cite{Iyer2014,Drivas2022}.
\end{remark}

\section{Numerical Methods}
\label{sec:numerics}

\subsection{Spectral Discretisation}

We discretise $[0,1]^2$ on an $N\times N$ grid with spacing $dx = 1/N$,
using the DFT convention

\begin{equation}
  \hat f[k_y,k_x]
  = \sum_{i=0}^{N-1}\sum_{j=0}^{N-1} f[i,j]\,e^{-2\pi i(ik_y+jk_x)/N}.
\end{equation}

Row index $i$ corresponds to the $y$-direction and column index $j$ to the
$x$-direction.
The centred wavenumbers are
$k_{\text{eff}}[j] = j - N\cdot\mathbf{1}[j>N/2]$,
giving the range $\{0,1,\ldots,N/2-1,-N/2+1,\ldots,-1\}$.

\paragraph{Derivative operators.}
The $x$- and $y$-derivative multipliers are stored as broadcast arrays:

\begin{equation}
  \texttt{DEL\_X}[0,j] = 2\pi i\,k_d[j],\qquad
  \texttt{DEL\_Y}[i,0] = 2\pi i\,k_d[i],
\end{equation}

where $k_d$ is identical to $k_{\text{eff}}$ except that the Nyquist mode
$k = N/2$ is set to zero (to avoid aliasing in first derivatives).

\paragraph{Inverse Laplacian.}
\begin{equation}
  \texttt{LAP\_INV}[k_y,k_x]
  = \begin{cases}
      \dfrac{-1}{(2\pi)^2(k_x^2+k_y^2)} & (k_x,k_y)\neq(0,0),\\[6pt]
      0 & (k_x,k_y)=(0,0).
    \end{cases}
\end{equation}

\paragraph{Mix-norm weight.}
\begin{equation}
  \texttt{LAMBDA\_INV}[k_y,k_x]
  = \frac{1}{2\pi|k|}
  = \sqrt{-\texttt{LAP\_INV}[k_y,k_x]}.
\end{equation}

\paragraph{Parseval identity.}
For the unitary DFT normalisation used here,
$\norm{\hat f}_{\ell^2} = N\norm{f}_{\ell^2}$, so

\begin{equation}
  \norm{f}_{L^2} = \frac{\norm{\hat f}_{\ell^2}}{N^2}.
\end{equation}

\subsection{Pseudo-Spectral Evaluation of the RHS}
\label{sec:rhs}

At each RK45 stage the following five steps compute $\partial_t\hat\theta$:

\begin{enumerate}
  \item \textbf{Compute} $g = \theta\,\nabla\lapinv\theta$ in physical space
        (pseudo-spectral):
        \[
          \hat g_x = \mathcal{F}\!\left[\theta\cdot\mathcal{F}^{-1}
            (\texttt{DEL\_X}\cdot\texttt{LAP\_INV}\cdot\hat\theta)\right],
          \quad
          \hat g_y = \mathcal{F}\!\left[\theta\cdot\mathcal{F}^{-1}
            (\texttt{DEL\_Y}\cdot\texttt{LAP\_INV}\cdot\hat\theta)\right].
        \]

  \item \textbf{Project} onto divergence-free fields (Leray):
        \[
          \widehat{\Proj g}_x = \hat g_x
            - \texttt{DEL\_X}\cdot\texttt{LAP\_INV}
              \cdot(\texttt{DEL\_X}\cdot\hat g_x+\texttt{DEL\_Y}\cdot\hat g_y),
        \]
        and similarly for the $y$-component.

  \item \textbf{Compute} $v = -\lapinv\Proj g$:
        \[
          \hat v_x = -\texttt{LAP\_INV}\cdot\widehat{\Proj g}_x,\qquad
          \hat v_y = -\texttt{LAP\_INV}\cdot\widehat{\Proj g}_y.
        \]

  \item \textbf{Normalise} to enforce the enstrophy constraint via Parseval:
        \[
          \norm{\nabla v}_{L^2}
          = \frac{1}{N^2}\sqrt{
              \norm{\texttt{DEL\_X}\hat v_x}_{\ell^2}^2
              +\norm{\texttt{DEL\_X}\hat v_y}_{\ell^2}^2
              +\norm{\texttt{DEL\_Y}\hat v_x}_{\ell^2}^2
              +\norm{\texttt{DEL\_Y}\hat v_y}_{\ell^2}^2},
          \quad
          u = F\,\frac{v}{\norm{\nabla v}_{L^2}}.
        \]

  \item \textbf{Advect}:
        \[
          \frac{d\hat\theta}{dt}
          = -\mathcal{F}\!\left[
              u_x\cdot\mathcal{F}^{-1}(\texttt{DEL\_X}\cdot\hat\theta)
              + u_y\cdot\mathcal{F}^{-1}(\texttt{DEL\_Y}\cdot\hat\theta)
            \right].
        \]
\end{enumerate}

\subsection{Time Integration}

The ODE is integrated with the Dormand--Prince RK45 method
(\texttt{scipy.integrate.solve\_ivp}, \texttt{method='RK45'}) with tolerances
$\texttt{rtol}=10^{-6}$ and $\texttt{atol}=10^{-8}$, matching the MATLAB
\texttt{ode45} default behaviour.

Because \texttt{scipy} requires a real-valued state vector, the complex
Fourier array $\hat\theta\in\mathbb{C}^{N^2}$ is stored as a real vector
$y = [\operatorname{Re}(\hat\theta_{\text{flat}}),\,
       \operatorname{Im}(\hat\theta_{\text{flat}})]\in\mathbb{R}^{2N^2}$.

\subsection{Resolution Check and Stopping Criterion}

Under incompressible advection all $L^p$ norms of $\theta$ are conserved.
We monitor the event function

\begin{equation}
  e(t) = \max\!\left(
    |\norm{\theta}_{L^2}-1|,\;
    \frac{\norm{\theta}_{L^4}}{\norm{\theta_0}_{L^4}}-1\Bigg|,\;
    \left|\frac{\norm{\theta}_{L^8}}{\norm{\theta_0}_{L^8}}-1\right|
  \right) - \varepsilon,
  \quad \varepsilon = 10^{-3}.
\end{equation}

Integration stops when $e(t)$ crosses zero upward, indicating that the
grid can no longer resolve the fine-scale features of $\theta$.

\section{Simulation Results}
\label{sec:results}

All results use $N=64$ spectral modes per direction and enstrophy constraint
$F=1$.
The simulation starts at $t=0$ and runs until the resolution check event fires.

\subsection{Spatial Evolution of the Scalar Field}
\label{sec:snapshots}

Figure~\ref{fig:snaps} shows six snapshots of the scalar field $\theta(x,y,t)$
for $a=0.5$, sampled evenly between $t=0$ and the stopping time $t=1.30$.
The LTD velocity progressively stirs $\theta$ into finer and finer filaments,
consistent with exponential decay of the mix norm.

\begin{figure}[H]

\subsection{Mix Norm Decay}
\label{sec:mixnorm}

Figure~\ref{fig:mixnorm} shows $\log(\norm{\theta(t)}_{H^{-1}} /
\norm{\theta_0}_{H^{-1}})$ for $a=0.5$.
After a brief initial transient the decay is well approximated by a linear
fit (dashed), confirming approximately exponential decay:

\begin{equation}
  \norm{\theta(t)}_{H^{-1}} \approx \norm{\theta_0}_{H^{-1}}\,e^{-\lambda t},
\end{equation}

with fitted decay rate $\lambda \approx 0.44$ for $a=0.5$.

\begin{figure}[H]
  \centering
  \includegraphics[width=0.75\linewidth]{figures/fig3_mixnorm_single.pdf}
  \caption{%
    Log of the $H^{-1}$ mix norm vs.\ time for $a=0.5$.
    The dashed line is the least-squares linear fit over the full trajectory,
    giving slope $-0.4400$ (decay rate $\lambda=0.44$).
  }
  \label{fig:mixnorm}
\end{figure}

\subsection{Conservation Law Verification}
\label{sec:conservation}

Figure~\ref{fig:lp} confirms that the $L^2$, $L^4$ and $L^8$ norms remain
$\approx 1$ throughout the integration.
The norms begin to drift near $t=1.3$, at which point the resolution check
terminates the simulation.
The maximum $L^2$ drift observed is $\max_t|\norm{\theta}_{L^2}-1|
\approx 2\times10^{-4}$, well within the tolerance $\varepsilon=10^{-3}$.

\label{sec:rate}

trajectory (discarding the initial transient), and define the mixing
timescale as $\tau(a) = -1/\lambda(a)$ where $\lambda(a)$ is the fitted slope.

\begin{remark}
  The observed scaling $\lambda\sim a^{-1.78}$ deviates from the
  theoretical $a^{-1}$ prediction of \cite{LTD2011}.
  This is consistent with the known fact that the greedy LTD velocity
  does not in general achieve the theoretically optimal mixing rate;
  see \cite{Iyer2014,Drivas2022} for lower-bound results.
  Longer integration times (larger $N$ to delay the resolution event) may
  be needed to isolate the asymptotic regime.
\end{remark}

\subsection{Key Design Choices}

\paragraph{Real/imaginary splitting.}
\texttt{scipy.integrate.solve\_ivp} requires a real-valued ODE.
The complex Fourier state $\hat\theta\in\mathbb{C}^{N^2}$ is stored as
$y = [\operatorname{Re}(\hat\theta),\,\operatorname{Im}(\hat\theta)]
\in\mathbb{R}^{2N^2}$, reconstructed at each RHS evaluation.

\paragraph{Broadcasting vs.\ full matrices.}
MATLAB uses dense $N\times N$ matrices \texttt{del\_x} and \texttt{del\_y}
where every row (resp.\ column) is identical.
Python stores these as shape-$(1,N)$ and shape-$(N,1)$ arrays that broadcast
automatically, saving memory and achieving the same element-wise products.

\paragraph{Closures instead of globals.}
The MATLAB code relies on \texttt{global} variables to pass operator arrays
into \texttt{convection\_hat.m}.
The Python port uses closures: \texttt{make\_convection\_hat(ops)} returns a
function that has already captured \texttt{DEL\_X}, \texttt{DEL\_Y} and
\texttt{LAP\_INV}.

\end{enumerate}

\section{Conclusions}
\label{sec:conc}

We have ported Gautam Iyer's MATLAB simulation of optimal passive-scalar
mixing to a fully documented Python module.
The Python code reproduces all the MATLAB results to within numerical
precision and adds Jupyter notebooks, automated figure generation, and a
packaging structure suitable for reproducible research.

The main numerical findings are:
\begin{itemize}
  \item The $H^{-1}$ mix norm decays approximately exponentially under the
        LTD optimal velocity, consistent with the theoretical predictions of
        \cite{LTD2011}.
  \item The mixing timescale $\tau(a) = -1/\lambda(a)$ grows with $a$,
        confirming that scalars with wider initial support mix more slowly.
  \item The observed power-law scaling $\lambda\sim a^{-1.78}$ deviates
        moderately from the predicted $a^{-1}$, likely due to resolution
        constraints limiting the duration of the asymptotic mixing regime.
  \item The $L^p$ conservation laws provide a robust stopping criterion:
        the simulation halts automatically when the grid can no longer
        resolve the scalar's fine-scale structures.
\end{itemize}

Future work could explore:
\begin{itemize}
  \item Higher resolution ($N=128$ or $N=256$) to access the asymptotic regime.
  \item Alternative initial data (e.g.\ random fields) and their effect on
        the mixing rate.
  \item Comparison with non-greedy optimal strategies.
\end{itemize}
